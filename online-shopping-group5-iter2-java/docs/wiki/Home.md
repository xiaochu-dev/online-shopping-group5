## 项目简介

基于统一基线需求的「单商品售卖」在线购物系统：卖家登录后台发布商品，买家免注册提交购买意向，系统按先到先得排队、口令码撤销、进入交易自动冻结、交易结果由卖家标记。本学期在此基线上按迭代逐步升级为多商品、多用户、在线支付的完整系统。

**当前进度（第 2 次迭代，2026-10-09 ~ 10-22）**：按课程要求将系统由 Python/FastAPI 迁移至 **Java 17 + Spring Boot 3 + MyBatis-Plus + Thymeleaf + SQLite**，数据库设计、页面结构与业务规则沿用迭代 1 并做功能增强——商品由「单件在售」升级为**多商品**，新增分类字典与分类筛选、关键词搜索、商品上下架状态流转、意向提交即入队与口令码撤销。迭代 1 的 Python 版本保留在仓库 `main` 分支，作为原型参考；迭代 2 的代码在 `iter2-java` 分支。

## 快速入口

### 迭代 2（Java / Spring Boot，默认）

- 卖家登录：`http://localhost:8080/login`（初始账号 admin / admin12345，首登后请改密）
- 卖家后台：`http://localhost:8080/admin`
- 基座自检：`http://localhost:8080/admin/diagnostics`（实时查看四张表的结构与行数）
- 启动方式：双击仓库根目录 `run.bat`，或执行 `mvnw.cmd spring-boot:run`

### 迭代 1（Python / FastAPI 原型，保留对照）

- 买家页面：`http://127.0.0.1:8000/product`
- 卖家后台：`http://127.0.0.1:8000/admin`

- 仓库源代码：`https://github.com/xiaochu-dev/online-shopping-group5`

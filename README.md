# 在线购物系统 MVP · 第 5 组（卖家后台）

组长（胡成溯）署名模块的可运行交付包。技术栈：Python 3.12 + FastAPI + sqlite3（标准库）+ Jinja2，端口 8000。

## 运行方式

方式一：双击 `run.bat`（自动 `pip install -r requirements.txt` 后启动）。

方式二：手动执行：

```bash
pip install -r requirements.txt
python main.py
```

启动后：

- 买家页（无需登录）：http://127.0.0.1:8000/product
- 卖家后台：http://127.0.0.1:8000/admin （未登录会重定向到 /login）
- 登录账号：`admin` / `admin12345`

## 冒烟测试

```bash
python test_smoke.py
```

使用 `fastapi.testclient.TestClient` 覆盖登录、发布、意向提交、冻结、撤销、递补、标记结果、历史、改密码全流程。

## 数据库

- 默认写入系统临时目录（`%TEMP%/online_shop_mvp.db`），不在交付目录留 `.db` 文件
- 可用环境变量 `DB_PATH` 指定自定义路径
- 种子卖家账号由 `db.py` 初始化（仅一个，符合 FR-01-1）

## 需求覆盖

| 需求 | 说明 |
|---|---|
| FR-01 卖家登录与账号管理 | 登录/改密/无退出登录，见 `auth.py`、`main.py` 登录与改密路由 |
| FR-02 商品发布 | 名称/价格必填、价格>0 两位小数、图片 JPG/PNG ≤5MB、同一时间仅一件 |
| FR-03 商品浏览与意向提交 | 买家免登录浏览、冻结提示「商品交易中」、口令码当场显示 |
| FR-04 意向队列与排队规则 | 提交时间正序（毫秒+id 兜底）、凭口令码撤销、位次前移 |
| FR-05 后台意向购买人管理 | 姓名/电话/提交时间正序，仅队首可点「进入交易」 |
| FR-06 商品冻结与解冻 | 自动/手动冻结同一状态、冻结不收新意向、解冻恢复在售 |
| FR-07 交易结果标记 | 仅卖家标记；成功下架入历史，失败递补或恢复在售 |
| FR-08 历史商品记录 | 倒序+分页（每页 5 条）、商品级/意向人级字段完整、只读 |

## 页面与操作

所有后台路由使用已有卖家登录拦截器，卖家编号取 Session，表单不能指定他人 sellerId。表单采用 POST/Redirect/GET，以 Flash 消息返回具体提示。

| 方法与地址 | 入参 | 行为 |
| --- | --- | --- |
| GET /admin/categories | 无 | 分类维护 |
| POST /admin/categories | name、parentId（空为一级）、sortNo | 新建分类，拒绝第三级与同父级重名 |
| POST /admin/categories/{id}/status | enabled | 启用或停用；停用父级隐藏整棵子树 |
| POST /admin/categories/{id}/delete | 无 | 只删无子类、无商品引用的分类 |
| GET /admin/products | status（选填） | 本卖家的商品及状态筛选 |
| GET /admin/products/new | 无 | 发布页，/publish 为同页入口 |
| POST /admin/products | name、price（元）、categoryId、stock、description、images、imageOrder、primaryIndex | 发布，分类必须为启用的二级分类；库存为非负整数 |
| POST /admin/products/{id}/stock | stock | 调整库存；归零自动下架并结束 pending 队列 |
| POST /admin/products/{id}/off-shelf | 无 | 手动下架，不扣库存 |
| POST /admin/products/{id}/relist | 无 | 有库存方可重新上架；仍有交易时恢复 frozen |

没有商品改名、改价、改图或删除路由。发布前有确认步骤。

`images` 最多9张；`imageOrder` 是原始文件下标的完整排列（0起始），`primaryIndex` 是原始文件下标。发布前调整顺序与封面，发布后不再改图。图集查询封面优先，其余按 sort_no；数据库 image_path 同步保存封面。

## 库存状态

- 发布库存>0：on_sale；库存=0：off_shelf / auto。
- 确认交易：frozen，库存不变；交易失败由现有交易模块处理，库存不变。
- 交易成功扣1：仍有库存则通过 release 恢复在售；归零则 off_shelf / auto，同事务将 pending 意向置 failed。
- release 只处理 frozen，不能覆盖自动下架或卖家手动下架。
- 卖家手动下架：off_shelf / manual，补货不自动上架。交易中的商品允许手动下架；已有交易仍可结束，重新上架时若有交易则恢复 frozen。
- 交易未结束时不允许把库存直接调成0，避免进行中的订单失去可扣库存。此项为实现约束，需要组内联调时确认。

## 图片与富文本

图片按空文件、5×1024×1024字节上限、JPG/JPEG/PNG扩展名、文件头、完整解码依次检查；图片像素上限4000万。全部校验成功才写盘。随机文件名，数据库保存相对路径；数据库事务失败会清理本次新文件。不传图使用占位图。

Jsoup 白名单允许段落、加粗、列表、链接与图片；删除脚本、事件属性及不安全协议。iframe 仅放行 HTTPS 的 `player.bilibili.com/player.html`、`www.youtube.com/embed/`、`www.youtube-nocookie.com/embed/`，设置 sandbox。域名须精确匹配，禁止伪装域、用户信息及其他端口。

外站视频的真实播放受网络、平台限制和视频本身影响。本轮验证了白名单过滤和嵌入输出，没有取得外站视频播放成功证据。

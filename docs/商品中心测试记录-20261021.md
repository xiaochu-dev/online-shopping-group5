## 环境与命令

Windows，Oracle JDK25，Maven3.9.11；源码按 Java17 release 编译。本机 Byte Buddy 旧版本不直接支持 JDK25，因此执行时加实验兼容开关：

```powershell
mvn -Dnet.bytebuddy.experimental=true test
```

新测试都使用独立数据库及上传目录，存于 target 下。没有连接原课程数据库。没有生成交付ZIP或运行 Maven package。
